# 打样染缸预约台

替代白板排期的染缸预约系统：批次登记、按染缸×时刻占位、冲突拦截、加急插单、变更退回待确认，以及空档 / 交期风险 / 调整历史视图。

## 核心规则

- **批次登记**：订单、客户、面料、色差目标（ΔE 上限）、配方、预计染程/保温、后整理、交期、加急标记。
- **留待排**：色差目标未定、缺配方或配方未复核、染程为 0 的批次不能上机。
- **占位**：按染缸与开始时刻预约，自动计入缸间缓冲；同一染缸重叠（含缓冲）直接拦截，开始时刻须对齐刻度、落在每日工作时段内。
- **加急插单**：可把已排批次向后平移（可换缸），待确认批次让位；开染中（running）块为固定障碍绝不移动；平移后仍无空档可安置的批次退回待排并说明原因。
- **开染锁定**：已开染批次不能改工艺、不能被插单打乱，只能完工出缸。
- **变更退回待确认**：配方 / 保温时间 / 后整理 / 染程时长变更后，已排批次进入「待确认」，**保留旧排期快照与原因**；可保留旧排期（再次校验冲突）、自动改约或释放回待排。
- **规则独立维护**：缓冲、排产周期、刻度、工作时段、交期预警阈值改动后立即复核现有排期，冲突批次退回待确认（开染中除外）。
- **可观测**：空档视图（按日各缸可排空档，一键预约）、交期风险（已排按预计完工、待排按最早可排预测，脱期/缓冲不足两级）、调整历史时间线（全部动作留痕）。
- 数据保存在浏览器 localStorage，历史页可一键重置演示数据。

## 架构

- `src/domain/` — 领域模型（`types.ts`）、时间工具（`time.ts`）、纯函数排程引擎（`engine.ts`，不依赖 React，可单测）
- `src/store/` — reducer 状态层、localStorage 持久化、演示种子数据
- `src/ui/` — 页面各自独立维护：`BoardPage` 预约白板、`BatchesPage` 批次档案、`GapsPage` 空档、`RisksPage` 交期风险、`RulesPage` 排程规则 / 染缸台账、`HistoryPage` 调整历史

技术栈：React 19 + Vite + TypeScript，纯前端，无后端。

